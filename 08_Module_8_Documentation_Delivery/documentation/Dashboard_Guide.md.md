# EduVision – Dashboard Guide

## 1. Overview

EduVision is an interactive higher-education performance dashboard developed using Tableau.

The dashboard suite allows users to explore university rankings, research performance, student characteristics, and country-level education performance.

---

## 2. Dashboard Navigation

The dashboard suite contains:

1. Home
2. University Overview
3. Research Analytics
4. Student Analytics
5. Country Comparison

Users can navigate between these dashboards using the navigation controls.

---

## 3. EduVision Home

### Purpose

The Home dashboard provides an overall introduction and summary of the EduVision project.

### Main Components

- Project title
- Key performance indicators
- Top university information
- Dashboard navigation

### Usage

Use the Home dashboard as the starting point for exploring the EduVision dashboard suite.

---

## 4. University Overview

### Purpose

The University Overview dashboard provides a high-level analysis of university ranking and overall performance.

### Main Analysis

- Global university distribution
- Academic reputation
- Top university rankings
- Overall score analysis
- University performance comparison
- Institutional comparison

### Main KPIs

- Global Ranking Score
- Research Impact Score
- Overall Score
- Total Universities

### Usage

Users can explore university performance and compare universities using the available filters and visualizations.

---

## 5. Research Analytics

### Purpose

The Research Analytics dashboard focuses on research performance across universities.

### Main Analysis

- Research impact
- Research productivity
- Research performance distribution
- Research comparisons
- Research impact by country

### Main KPIs

- Research Productivity Index
- Research Impact Score
- Global Ranking Score
- Overall Score

### Usage

Use this dashboard to identify universities and countries with stronger research-related performance.

---

## 6. Student Analytics

### Purpose

The Student Analytics dashboard focuses on student-related university indicators.

### Main Analysis

- International students
- Faculty-to-student ratio
- Student diversity
- International student distribution
- Student comparison
- International students by country

### Main KPIs

- International Student Percentage
- Faculty-to-Student Ratio
- Global Ranking Score
- Overall Score

### Usage

Use this dashboard to analyze student diversity and student-related university performance.

---

## 7. Country Comparison

### Purpose

The Country Comparison dashboard provides country-level education performance analysis.

### Main Analysis

- University count by country
- Country performance comparison
- Overall score comparison
- Research impact comparison
- Country performance benchmarking
- Country-level performance distribution

### Main KPIs

- Total Universities
- Total Countries
- Average Overall Score
- Global Ranking Score

### Usage

Select a country to analyze and compare its higher-education performance.

---

## 8. Filters

The dashboard suite provides interactive filtering capabilities.

### Country

Filters analysis based on the selected country.

### University Name

Allows users to focus on a particular university.

### Global Ranking Score Range

Allows users to analyze universities within a selected ranking-score range.

---

## 9. Navigation

Use the navigation buttons to move between:

```
Home
↓
University Overview
↓
Research Analytics
↓
Student Analytics
↓
Country Comparison
```
